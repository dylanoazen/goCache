# goCache

A mini Redis-like cache server built in Go to study:

- TCP sockets
- concurrency
- goroutines
- mutexes
- persistence
- distributed systems
- observability
- benchmarking

## Goals

This project was created to learn backend and systems engineering concepts using Go.

## Features

- [ ] In-memory cache
- [ ] TCP server
- [ ] SET/GET commands
- [ ] concurrency handling
- [ ] persistence
- [ ] replication
- [ ] observability

## Tech Stack

- Go
- Docker
- AWS EC2
- Prometheus
- Grafana

## Running

```bash
go run ./cmd/server
go run ./cmd/client
```
